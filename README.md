# 📊 Sorting Visualizer

An interactive sorting algorithm visualizer that animates how different sorting algorithms rearrange data step by step, helping you understand their efficiency and behavior.

## ✨ Features

- Visual, animated comparison of sorting algorithms
- Client/server architecture bundled with Webpack
- Adjustable visualization for algorithm behavior

## 🧰 Tech Stack

JavaScript, Webpack, Babel, Node.js (client/server structure)

## 🚀 Getting Started

```bash
git clone https://github.com/AmnaKhan1323/Sorting-Visualizer.git
cd Sorting-Visualizer
npm install
npm start
```
